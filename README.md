# 살롱 드 벨르 : created by 홍길동

바로크풍의 우아한 분위기를 담은 카페 홈페이지입니다. 아이보리와 버건디, 골드 컬러를 사용해 따뜻한 살롱 분위기를 표현했습니다.

## 주요 기능

- 카페 소개, 메뉴, 브랜드 이야기, 위치·영업시간·문의 정보 제공
- 커피, 디저트, 티 메뉴를 카테고리별로 필터링
- 메뉴를 담으면 주문 개수가 업데이트되는 인터랙션
- 버튼으로 라이트 모드와 다크 모드 전환
- 모바일 화면용 반응형 레이아웃과 내비게이션
- 운영자 연락처를 포함한 페이지 하단 정보

## 실행 방법

별도의 설치나 빌드 과정은 필요하지 않습니다. `index.html` 파일을 웹 브라우저에서 열면 됩니다.

```text
week11-mini/
├── index.html
└── README.md
```

HTML 파일 안에 CSS와 JavaScript가 포함되어 있어 정적 웹 호스팅에도 바로 배포할 수 있습니다.

## 외부 리소스

글꼴은 Google Fonts, 카페 사진은 Unsplash 이미지 URL을 사용합니다. 해당 리소스를 표시하려면 인터넷 연결이 필요합니다.
